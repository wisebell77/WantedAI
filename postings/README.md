# `postings/` — 맞춤 공고 추천 (지금 모집 중)

담당: 김소연 · 브랜치 `feat/persona`

## 한 줄 요약
내 경험을 넣으면 **오늘 기준 마감 전인 민간 공고** 중 겹침이 큰 것을 근거와 함께 추천하고,
고른 공고로 바로 서류 심사·면접 연습(`persona/`)으로 넘어간다.

## 직무추천 파트와의 관계
| | 직무추천 (recommendation 브랜치) | 공고 추천 (여기) |
|---|---|---|
| 답하는 질문 | 어떤 **직무**가 나와 맞나 | 그 직무의 **어떤 공고에 지금** 지원하나 |
| 데이터 | ALIO 공공 직무기술서 2022~2025 (지난 공고) | 고용24 공채속보 목록 + 기업 채용페이지 본문 |
| 단위 | NCS 소분류 | 민간 공고의 직무 |

연결: 직무추천 결과 이름을 `UserProfile.ncs_matches` 로 넘기면 `NCS_TO_JOB` 표로 민간 직무군에 가점.
이 표는 임시다 — 추천 파트와 합의 필요.

## 데이터 흐름
```
공채속보 API 목록 (마감일 포함) ──┐
                                  ├─ 오늘 이전 마감 제외 ─► 모집 중 공고
기업 채용페이지 본문(jd_tiered) ──┘                           │
roles.json (직무 단위) ────────────────────────────────────────┤
                                  본문 있음 + A/B등급 ─► 대조 대상
                                  본문 없음 ─► '본문 미수집' (제목으로만 관련 표시)
```

## 점수 (설명 가능한 것만)
| 요소 | 비중 | 내용 |
|---|---|---|
| 기술 겹침 | 0.45 | 내 경험 속 기술 ∩ 공고 기술, 드문 기술일수록 무겁게(IDF) |
| 요건 겹침 | 0.35 | 공고 요건 문장과 내 경험 문장의 유사도(글자 2-gram) |
| 직무 적합 | 0.20 | 희망 직무군·직무추천 결과와 같은 직무군 |
| 전공 | +0.10 | 내 전공명이 공고에 등장 |

- 한 공고의 직무가 목록을 도배하지 않도록 **공고당 1개**만.
- 상위 3건은 `persona.review_letter` 로 다시 본다 → 서류 반영도·준비 필요 항목 (키가 있으면 AI).
- 자격은 **걸러내지 않고 표시**: `[지금 지원 가능]` / `[준비 필요 (경력 1년 이상 요구)]`.
  '우대'가 붙은 줄은 요구 조건으로 보지 않는다.

## 실행
```bash
python demo_postings.py                      # 개발 지망 예시
python demo_postings.py --profile biz        # 경영지원 지망 예시
python demo_postings.py --today 2026-09-12   # 기준일 고정(발표 재현)
python scripts/refresh_open_postings.py      # 공채속보 목록 갱신 (.env 에 WORK24_KEY_RECRUIT)
python scripts/build_rubrics.py --open-only  # 모집 중 공고 채점표를 AI로 미리 만들어 저장 (시연 전 1회)
```
필요 파일(`data/overlap/`): `roles.json`, `jd_tiered.json`, `공채속보_원본350.json`(또는 갱신본 `gongchae_open.json`)
