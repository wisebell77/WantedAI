# `web/` — 로컬 확인용 화면

**엔진이 내놓는 걸 눈으로 보려고 만든 것이다.** 배포용이 아니다.
숫자표만 보면 어디가 부족한지 모른다. 화면에 올려 놓으면 깨진 역량 이름이나
말이 안 되는 근거가 바로 눈에 띈다 — 실제로 그렇게 여러 개를 찾았다.

```bash
python web/server.py            # http://127.0.0.1:8000
python web/server.py --port 9000
```

엔진은 시작할 때 한 번 올린다(임베딩 모델 로딩에 20초쯤). 그 뒤 요청은 빠르다.

## 파일

| 파일 | 내용 |
|---|---|
| `server.py` | 표준 라이브러리 HTTP 서버. `Engine` 이 엔진 한 벌을 들고 요청을 받는다 |
| `static/index.html` | 화면 전부. 빌드 도구 없이 파일 하나 |

## 왜 Flask·FastAPI 를 안 썼나

**설치 없이 팀원이 바로 돌려 볼 수 있어야 해서다.** 이미 torch·sentence-transformers
때문에 설치가 무거운데 여기에 웹 프레임워크까지 얹을 이유가 없다.
`http.server` 로 충분하다 — 엔드포인트가 셋뿐이다.

배포는 이 파일로 하지 않는다. `http.server` 는 개발용이라 동시 접속·보안 처리가 없다.
서비스로 올릴 때는 구조(엔진을 한 번 올리고 JSON 을 주고받는 것)만 가져간다.

## 엔드포인트

| 메서드 | 경로 | 하는 일 |
|---|---|---|
| GET | `/` | 화면 |
| GET | `/api/jobs` | **정방향 목표 목록**(소분류 41 + 세분류 81) · 프리셋 · LLM 여부 |
| POST | `/api/tidy` | 긴 글 → 경험 문장. LLM 있으면 쓰고 없으면 규칙 |
| POST | `/api/recommend` | `{texts, target?, seen?, limit?}` → 대조 결과 |

`target` 을 주면 정방향(그 직무와의 격차), 안 주면 역방향(겹침이 많은 직무)이다.

## 모드는 토글로 가른다

정방향과 역방향은 **묻는 것이 다르다.** 한 목록에 섞어 두면
"역방향" 한 줄 아래 직무 122개가 붙어 무엇을 고르는 화면인지 알 수 없다.
토글로 먼저 가르고, 정방향일 때만 목표 선택창을 연다.

목표는 **소분류와 세분류를 함께** 낸다. 잘 모르겠으면 소분류(`정보기술전략·계획`),
희망 직무가 구체적이면 세분류(`정보기술전략·계획 › 빅데이터분석`)를 고른다.

122개를 스크롤로 찾는 건 무리라 **입력하면 실시간으로 좁히는 선택창**을 썼다.
`빅데이터` 를 치면 한 줄로 줄어든다.

세분류를 목표로 잡아도 근거는 나온다. 근거 인덱스는 소분류 단위로만 만들지만
(세분류까지 만들면 (직무, 역량) 쌍이 11,113 → 57,600 으로 늘어 파일이 다섯 배),
세분류 단위는 소분류 단위의 부분집합이라 같은 공고 풀에서 나온다.
`EvidenceIndex.quotes` 가 8자리 코드를 6자리로 넘겨 받는다.

## 화면에 무엇이 나오나

```
정보기술개발
  정보기술개발 공고가 요구하는 역량 중 6개가 당신의 경험과 겹칩니다 (공고 97건 · 기관 48곳)

  겹치는 역량
    리뷰진행                                      공고 5건에서 요구
      당신의 경험 — 깃으로 브랜치를 나눠 협업하고 코드 리뷰를 진행했다
      공고 원문   — 리뷰 진행 기술
                    국방과학연구소 2023년 하반기 임용 공개채용   [링크]

  이 직무를 이렇게 정의한 공고
    한국주택금융공사 2024년 하반기 체험형 인턴 채용공고
      당신과 겹치는 역량 2개 — IDE및개발환경도구활용 · 리뷰진행
```

맨 아래 **"엔진이 읽은 것"** 패널이 디버깅용이다. 문장이 어떤 역량 노드로 읽혔는지,
사전에 못 붙은 문장이 무엇인지 그대로 보여 준다. 화면을 만들자마자 여기서
`o웹서비스의트렌드및웹프로그래밍`(불릿 문자 잔해)과 `리깅`(잘못된 군집)이 나왔다.

## 지키는 것

- **퍼센트를 띄우지 않는다.** 겹치는 개수와 근거 문장만.
- **대표 공고에는 경고를 붙인다.** 2022~2025년 공공기관 채용공시라 대부분
  마감됐다. "지원하세요"가 아니라 "이 직무가 무엇을 요구하는지의 근거"다.
  지금 지원 가능한 공고는 공채속보(민간) 쪽이고 아직 화면에 안 붙였다.
- **판단 로직을 여기에 두지 않는다.** 서버는 엔진을 호출하고 JSON 으로 옮길 뿐이다.
  화면에서 규칙을 어기면 엔진이 지킨 게 무의미해진다.

## 다른 폴더와의 관계

- `overlap.Recommender` 를 그대로 쓴다. 이 폴더에만 있는 계산은 없다.
- `overlap.UpstageClient` 는 **입력 다듬기에만** 쓴다. 추천은 LLM 을 타지 않는다.
  키(`UPSTAGE_API_KEY`)가 없으면 규칙 분리로 돌아가고 화면에 그렇게 표시된다.
- 프리셋 3종이 `server.py` 에 있다. `pipelines/recommend_demo.py` 와 같은 내용이니
  바꿀 때 양쪽을 맞춘다.
