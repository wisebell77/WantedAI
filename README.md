# Overlap Interview Lab — 초기 MVP

취업준비생이 선택한 직무의 질문에 영상으로 답하고, 브라우저에서 수집한 음성 지표와 답변 텍스트를 바탕으로 연습 피드백을 받는 프론트엔드 MVP입니다.

## 실행

정적 파일 서버로 `dist` 폴더를 실행하세요. 카메라와 마이크는 `localhost` 또는 HTTPS 환경에서만 정상적으로 권한을 요청합니다.

```bash
python3 -m http.server 4173 --directory dist
```

그다음 브라우저에서 `http://localhost:4173`을 엽니다.

## 현재 구현 범위

- 데이터 분석가, 서비스 기획·PM, 퍼포먼스 마케터 질문/평가 기준
- 브라우저 카메라·마이크 연결과 MediaRecorder 녹화
- Web Speech API를 지원하는 브라우저의 한국어 자동 전사
- 음성 크기 샘플을 이용한 긴 침묵과 목소리 변화 측정
- 전사 텍스트의 말하기 속도, 습관어, 답변 구조, 직무 신호 분석
- 자동 전사 미지원 시 직접 입력 후 재분석

## 의도적으로 제외한 범위

- 녹화 파일 업로드·영구 저장
- 실제 LLM/API 연동과 후속 질문 생성
- 시선, 표정, 자세를 이용한 채용 적합도 판정
- 합격 가능성 점수
