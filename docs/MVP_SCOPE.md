# 화상면접 MVP 범위와 전문성 경계

## 제품 가설

취업준비생은 막연한 인상 평가보다, 선택한 직무의 평가 기준과 자신의 실제 답변에서 나온 근거를 함께 볼 때 다음 연습 행동을 더 구체적으로 정할 수 있다.

## 이번 MVP에서 검증할 흐름

1. 직무를 선택하고 직무별 질문과 평가 기준을 확인한다.
2. 카메라·마이크를 켜고 실제 답변을 녹화한다.
3. 브라우저가 음성 크기, 침묵 구간, 답변 시간을 측정한다.
4. Whisper small 모델을 브라우저에 내려받아 녹화된 음성을 한국어 텍스트로 전사한다. 전사 실패 시 사용자가 답변을 직접 붙여 넣는다.
5. 답변 텍스트에서 구조 신호, 직무 관련 근거, 수치, 습관어를 찾아 개선 행동을 제안한다.
6. 가장 덜 드러난 직무 루브릭 항목 하나를 골라 꼬리질문을 제시하고, 후속 답변까지 포함해 다시 평가한다.
7. 결과 화면에서 현재 세션의 녹화 영상·음성을 재생해 피드백과 대조한다. 영상은 서버에 저장하지 않는다.

## 현재 분석의 의미

- 답변 완성도는 합격 확률이 아니다.
- 직무 키워드는 공고 전체를 대표하지 않으며, MVP용 예시 평가 기준이다.
- 음량 변화와 침묵은 전달 습관을 돌아보기 위한 신호일 뿐 능력·성격·진실성을 나타내지 않는다.
- 영상은 녹화 경험을 제공하지만 얼굴 표정, 외모, 성별, 나이, 장애 여부를 평가하지 않는다.
- 루브릭 점수는 키워드·문장 패턴을 확인하는 초기 규칙 기반 지표이며, 실제 면접 결과나 합격 가능성의 예측값이 아니다.
- Whisper 모델 다운로드는 외부 모델 저장소를 이용하지만, 녹화 오디오 자체는 전사를 위해 외부 API로 전송하지 않는다.

## 전문 지식과 역량이 반드시 필요한 부분

| 영역 | 필요한 전문가 | 검증해야 할 내용 |
| --- | --- | --- |
| 직무별 평가 루브릭 | 해당 직무의 현업 면접관, 채용 담당자 | 실제 평가 기준, 질문 타당성, 좋은 답변 근거의 수준 |
| 평가 신뢰도 | 산업·조직심리 또는 평가측정 전문가 | 평가자 간 일치도, 예측 타당도, 점수 해석의 한계 |
| 한국어 음성 분석 | 음성 AI 엔지니어, 언어학 전문가 | 억양·속도·휴지 기준의 방언·성별·장애 편향, ASR 오류율 |
| 영상 행동 분석 | 컴퓨터 비전 엔지니어, HCI·접근성 전문가 | 시선·자세 추정 정확도, 조명·기기 차이, 신경다양성·장애 편향 |
| 개인정보·채용 윤리 | 개인정보보호/노무 법률 전문가 | 영상·음성 동의, 보관 기간, 삭제권, 자동화된 평가 고지와 차별 위험 |
| AI 피드백 품질 | LLM 엔지니어, 현업 평가자 | 근거 없는 피드백 방지, RAG 출처 품질, 출력 일관성과 안전성 |

## 프롬프트 이상의 전문성 확보 구조

상용 버전의 첨삭/면접 피드백은 다음처럼 구성하는 것이 적절하다.

1. 회사 JD와 검증된 직무 루브릭을 버전이 있는 데이터로 저장한다.
2. 답변을 주장, 행동, 근거, 결과 단위로 구조화한다.
3. 각 피드백이 어느 JD 문장·루브릭 항목·답변 구절에 근거하는지 연결한다.
4. 규칙 기반 측정과 LLM 해석을 분리하고 서로 충돌하면 불확실성을 표시한다.
5. 현업 평가자가 만든 기준 답변 세트로 정확성, 일관성, 편향을 반복 평가한다.
6. 민감한 영상 추론은 기본적으로 제외하고, 검증된 전달 행동만 사용자 동의 아래 피드백한다.

## 다음 개발 우선순위

1. 서버 기반 STT와 질문별 답변 저장: 브라우저 차이를 줄이고 여러 회차의 변화를 비교한다.
2. JD/RAG 기반 평가: 피드백 문장마다 출처와 답변 근거를 노출한다.
3. 동적 후속 질문: 앞 답변의 모호한 주장이나 빠진 근거를 대상으로 한 질문만 생성한다.
4. 전문가 평가 데이터셋: AI 결과와 현업 평가자의 일치도를 측정한다.
5. 개인정보 설계: 명시적 동의, 암호화, 자동 삭제, 내려받기·삭제 기능을 먼저 마련한다.
