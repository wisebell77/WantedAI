# 현재 MVP 정리

## 이 서비스가 하는 일

Overlap은 사용자가 선택한 채용공고와 본인의 경험을 함께 보고, 취업 준비를 정리해 주는 서비스입니다. 지금은 AI 코치 기능이 중심이고, 화상면접은 추가 기능입니다.

## AI 코치 화면

사용자는 다음 순서로 사용합니다.

1. 수집된 채용공고 하나를 선택한다.
2. 본인의 경험과 준비 상태를 적는다.
3. 타임라인, 자소서 시작, 이번 주 할 일을 요청하거나 직접 질문한다.
4. AI 코치는 선택 공고와 사용자가 적은 경험을 근거로 답한다.

AI 코치는 두 모델을 나누어 사용합니다.

- `solar-mini`: 타임라인, 할 일 정리처럼 형식이 비교적 정해진 요청
- `solar-pro4`: 자소서 시작 가이드, 직무 상담처럼 설명의 품질이 더 중요한 요청

API 키는 브라우저가 아닌 로컬 서버의 `.env`에서만 읽습니다.

## 공고를 바꿨을 때

공고마다 별도 세션을 사용합니다. 즉, A 공고에서 작성한 경험, 대화, 할 일은 B 공고에 섞이지 않습니다.

- 공고를 바꾸면 해당 공고의 기록만 불러온다.
- 경험 또는 마감일을 바꾸면 이전 답변이 더 이상 맞지 않을 수 있으므로, 해당 공고의 대화와 할 일을 비운다.
- 공고 본문에서 마감일을 찾을 수 있으면 자동으로 입력한다. 찾지 못한 공고만 사용자가 직접 입력한다.

현재 세션 기록은 브라우저에만 저장됩니다. 다른 기기나 다른 브라우저에서는 이어지지 않습니다.

## 채용공고 데이터가 쓰이는 방식

현재 로컬 데모 서버는 아래 두 파일을 읽어 공고 정보를 만듭니다.

- `Overlap_데이터_20260911/data/roles.json`: 회사명, 직무명, 직무군, 기술 키워드
- `Overlap_데이터_20260911/data/jd_tiered.json`: 정제된 공고 본문

이 폴더는 수집 원문을 포함할 수 있어 Git에 올리지 않습니다. 따라서 팀원이 저장소를 새로 받으면 이 데이터는 없으며, 크롤링 팀 API 또는 별도 승인된 테스트 데이터를 연결해야 합니다.

서버는 두 파일을 합쳐 공고별 `postingId`, 회사명, 직무명, 직무군, 업무 내용, 기술, 원문 주소, 마감일을 만듭니다. AI에는 전체 공고 모음이 아니라 사용자가 선택한 공고 한 건만 보냅니다.

## 화상면접 기능

- 카메라·마이크로 답변을 녹화하고 바로 다시 볼 수 있습니다.
- faster-whisper medium 모델이 선택 공고 JD의 용어 힌트와 함께 로컬 서버에서 음성을 글로 바꿉니다. 녹화 파일은 전사 직후 서버 임시 폴더에서 삭제됩니다.
- 말하기 속도, 긴 침묵, 습관어와 간단한 답변 구조를 보여 줍니다.
- 선택 공고 원문으로 직무별 채점표를 만들고 인용문이 실제 공고에 있는지 확인합니다. `InterviewSession`이 답변을 0~3점으로 평가하며 2점 미만이면 꼬리질문을 한 번 제시합니다.

면접 피드백은 연습용이며 실제 채용 결과를 예측하지 않습니다. 실제 면접관 수준으로 고도화하려면 전문가 검토가 필요합니다.

## 현재 한계

- 공고 본문 안의 마감일 찾기는 한국어 날짜 표현을 기준으로 한 초기 방식입니다. 날짜가 여러 개이거나 형식이 다르면 직접 입력이 필요할 수 있습니다.
- AI 응답은 공고와 경험을 근거로 하도록 제한했지만, 실제 채용 기준의 정확성을 보장하지 않습니다.
- 미리 생성한 `out/rubrics/{role_id}.json`이 있으면 서버가 이를 우선 사용하고, 공고 URL과 인용 근거를 확인합니다. 파일이 없거나 오래된 경우 요청 시 생성하고 서버 실행 중 메모리에 보관합니다.
- 말하기 속도·침묵·습관어·영상 랜드마크 지표는 브라우저에서 계산하는 연습용 지표입니다.
- 사용자 기록은 서버나 데이터베이스에 저장하지 않습니다.
